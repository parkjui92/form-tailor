# 양식 충실도 점검 항목

Phase 4에서 생성물을 샘플 프로파일과 대조할 때 쓰는 체크리스트. 각 항목을 ✅(일치) / ⚠️(부분·경미) / 🔴(누락·위반)로 판정하고, ⚠️·🔴은 **수정 위치**를 명시한다.

## 구조

- [ ] **섹션 골격·순서**: 프로파일 skeleton의 계층·순서가 그대로인가
- [ ] **필수 섹션 존재**: required_sections(요약◇·붙임 등)가 다 있는가
- [ ] **글머리 기호체계**: 각 레벨 기호(□ㅇ-*①Ⅰ)와 들여쓰기 칸이 샘플과 같은가
- [ ] **기호 이중부착 없음**: 텍스트에 기호가 중복으로 들어가지 않았는가

## 문체·표기

- [ ] **종결 어미**: 개조식(~함/~임)/서술체/경어체가 샘플과 일치하는가 (잔존 예외 위치 표시)
- [ ] **제목**: 길이·동작성 관행에 맞는가
- [ ] **날짜·시간 표기**: date_format 패턴을 따르는가
- [ ] **한 항목 한 초점**: 여러 내용이 한 항목에 뭉치지 않았는가
- [ ] **문장 길이**: 관행 줄 수(대개 ≤2줄)를 지키는가

## 머리·표·강조

- [ ] **머리 정보**: 제목·부제·서명·문서번호 위치/형식이 맞는가
- [ ] **표 관행**: 열 구성·헤더·정렬이 샘플과 유사한가
- [ ] **강조**: 볼드 대상이 핵심 명사 위주인가

## 서식 보존 — hwpx (kordoc)

- [ ] **글꼴·크기·줄간격·여백**: 원본 스타일이 보존됐는가(스타일 공여 경로)
- [ ] **표 보존**: 표가 텍스트로 평탄화되지 않았는가

## 서식 보존 — docx (python-docx)

> docx도 글꼴·여백 보존이 쟁점이다. hwpx 전용으로 오인해 건너뛰지 말 것.

- [ ] **여백·용지**: EMU가 원본과 일치하는가(신뢰 관측 필드)
- [ ] **제목 서식**: 글꼴·크기·정렬·볼드가 원본과 일치하는가
- [ ] **본문 글꼴**: 관측된 경우 재적용됐는가 / 관측 못 했으면(run·Normal 모두 None) 점검표에 `UNOBSERVED`로 정직히 표기했는가
- [ ] **표 헤더 음영**: `w:shd` 값이 재현됐는가
- [ ] **줄간격**: 관측 가능했으면 일치하는가(아니면 UNOBSERVED)

## 안전

- [ ] **사실 불변**: 수치·고유명사·주장이 원 내용과 동일한가(양식 변환이 의미를 바꾸지 않았는가)
- [ ] **샘플 개인정보 미복제**: 샘플의 실명 서명·연락처가 새 문서에 남지 않았는가

---

한 줄이라도 🔴이면 "양식 준수"라고 보고하지 않는다. ⚠️는 사용자 승인 후 반영한다.
